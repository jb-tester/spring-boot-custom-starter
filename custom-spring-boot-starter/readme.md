# 
The custom starter

It defines some custom autoconfiguration annotation
It imports some configurations from the library module in the
above annotation's imports file. 
Two of these configurations (local and imported) have an
`optional:` prefix.
It also defines some autoconfigurations with before/after conditions.
One of configurations is deprecated and replaced by another using the
`org.springframework.boot.autoconfigure.AutoConfiguration.replacements` file
